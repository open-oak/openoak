# Shared website wallpapers

Canonical non-blurred wallpaper set for the OpenTodo, OpenKanban, and
OpenOutline marketing websites. The OpenOak website background is not part of
this set.

| Output | Source |
| --- | --- |
| `wallpaper-04.webp`, `wallpaper-07.webp`, `wallpaper-09.webp` | `apps/todo/public/4.jpg`, `7.jpg`, `9.jpg` |
| `wallpaper-05.webp` | `samuel-scrimshaw-RD1tQOC_IF8-unsplash.jpg` |
| `wallpaper-06.webp` | `daniel-leone-g30P1zcOzXo-unsplash.jpg` |
| `wallpaper-10.webp`–`wallpaper-13.webp` | `websites/openoak/kanban/public/open_bg_1.webp`–`4.webp` |

Wallpapers 04–07 and 09 were auto-oriented, resized to a maximum 3000-pixel
edge, stripped of metadata, and encoded as quality-90 WebP images using encoder
method 6. Wallpapers 05 and 06 were replaced with the supplied Samuel
Scrimshaw palm and Daniel Leone mountain photographs. The marketing versions
of wallpapers 07 and 09–13 were resized to a maximum 2048-pixel edge and
encoded at quality 82 using method 6. The standalone and OpenOak-hosted pages
use identical copies.

Wallpapers 01, 02, 03, and 08 were intentionally excluded from the shared set.
