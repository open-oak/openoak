# Security

Report suspected vulnerabilities privately to openoaksoftware@proton.me. Include
the affected app and source revision, a concise reproduction, and the expected
and observed behavior. Use synthetic accounts and data for reproductions.

Do not put passwords, tokens, production data or exploit details in a public
issue. GitHub private vulnerability reporting can be used when it is enabled on
this repository.

Security fixes are maintained in the OpenOak monorepo. Archived app and website
repositories do not receive updates. Use the current monorepo source and review
migration notes before upgrading an installation.

The source license does not grant permission to test the hosted production
service or another person's installation. Arrange authorization with the operator
before testing an installation you do not control.
